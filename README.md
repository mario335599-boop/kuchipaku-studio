# 口パクスタジオ

キャラクター素材ZIPと音声から、9:16の字幕付き口パク動画を作るツールです。

[Web版を開く](https://mario335599-boop.github.io/kuchipaku-studio/)

## 使えること

- ChatGPT向けの制作キット・プロンプトからキャラクター素材ZIPを準備し、読み込んで切り替え。
- 母音の口、瞬き、髪・腕・キャラクターごとのアクセサリーを部品で動かす。
- 全身表示・上半身表示、拡大率と上下位置の調整。
- WAVのドロップ・ファイル貼り付けと、日本語音声の文字起こし。
- 字幕・読み・時間の編集、区間試聴、分割・結合。
- 背景テーマ、任意の背景画像、設定保存と復元。

## Web版とローカル版

Web版では、キャラクター・背景・字幕の編集とWebM保存がブラウザー内で動きます。自動字幕・日本語の読み生成・MP4保存は、ローカル版をパソコンで起動し、Web版の「起動済みの機能に接続」から使います。GitHub Pages上で音声認識のPythonを実行する仕組みではありません。

Web版内の「ローカル版を保存」からダウンロードし、展開後に「口パクスタジオを起動.sh」を実行してください。Python 3とvenvが必要です。初回のみ認識モデル・辞書等のダウンロードを行い、音声の認識は端末内で処理します。詳しくは同梱の「使い方.md」を参照してください。

任意のキャラは、キャラ選択の横にある制作キットとキャラクターシートを、画像生成・ファイル作成が使えるChatGPTのチャットへ添付して準備します。字幕の聞き間違いや区切りは編集して直せます。

カーマンは入れ替え可能なサンプルです。アクセサリー名・個数・取り付け先はキャラ素材ZIPから読み込みます。
